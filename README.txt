Score Snap — ฉบับใช้งานโดยไม่ต้องลงชื่อเข้าใช้
================================================

ติดตั้งเป็นแอปบนหน้าจอโฮม (หลังนำขึ้นเว็บแบบ https แล้ว)
- iPad / iPhone: เปิดลิงก์ใน Safari > แตะปุ่มแชร์ > "เพิ่มไปยังหน้าจอโฮม"
- Android / Chrome / Edge บนคอมพิวเตอร์: กดปุ่ม "ติดตั้ง" ที่แถบด้านบนของแอป หรือไอคอนติดตั้งในแถบที่อยู่
- เปิดครั้งแรกต้องต่ออินเทอร์เน็ต หลังจากนั้นใช้ออฟไลน์ได้ (ฟัง แก้ไข ส่งออก)
- ต้องการเสียงเครื่องดนตรีครบทุกชนิดตอนออฟไลน์: เปิดหัวข้อ "ใช้งานออฟไลน์" ในแอป แล้วกดดาวน์โหลดเสียงทั้งหมด (56 MB)
- เมื่ออัปเดตไฟล์บนเว็บ แอปจะโหลดเวอร์ชันใหม่เองเมื่อเปิดครั้งถัดไปขณะต่อเน็ต

วิธีนำขึ้นเว็บ (เลือกอย่างใดอย่างหนึ่ง) — ต้องเป็น https จึงติดตั้งและใช้ออฟไลน์ได้
1. GitHub Pages: สร้าง repository ใหม่ อัปโหลดทุกไฟล์ในโฟลเดอร์นี้ (index.html และโฟลเดอร์ sf) แล้วเปิด Settings > Pages > Deploy from branch
2. Netlify Drop: เข้า app.netlify.com/drop แล้วลากทั้งโฟลเดอร์ score-snap ไปวาง
3. เว็บเซิร์ฟเวอร์ของหน่วยงาน: คัดลอกทั้งโฟลเดอร์ไปไว้บนเซิร์ฟเวอร์

ทดลองบนเครื่องตัวเอง: เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์
    python3 -m http.server 8000
จากนั้นเปิด http://localhost:8000
(ถ้าดับเบิลคลิก index.html ตรงๆ จะใช้งานได้ แต่เสียงเครื่องดนตรีจริงจะโหลดไม่ได้ และจะใช้เสียงสังเคราะห์แทน)

สิ่งที่ใช้ได้โดยไม่ต้องลงชื่อเข้าใช้
- ฟังเสียง เลือกเครื่องดนตรี 128 ชนิด ปรับความเร็ว ทรานสโพส
- แก้ไขโน้ต ตรวจจังหวะ
- นำเข้า/ส่งออก MusicXML (MuseScore, Sibelius, StaffPad), MIDI, SVG, ABC

การอ่านโน้ตจากรูปด้วย AI
- ต้องใส่ Anthropic API key ของผู้ใช้เอง (สร้างที่ console.anthropic.com) ค่าใช้จ่ายคิดตามการใช้งานจริง
- key ถูกส่งตรงจากเบราว์เซอร์ไปยัง api.anthropic.com เท่านั้น และเก็บในเบราว์เซอร์เฉพาะเมื่อติ๊ก "จำ key"
- ห้ามใส่ key ของตัวเองลงในไฟล์ index.html ก่อนนำขึ้นเว็บสาธารณะ เพราะทุกคนจะเห็นและใช้ key นั้นได้

ฟอนต์และตัวแสดงโน้ตฝังอยู่ในโฟลเดอร์นี้แล้ว ไม่ต้องโหลดจากอินเทอร์เน็ต
